# 空中設置杖

```embed:item id=advancedschematicannon:air_placement_wand size=48 label=true
```

FEを消費し、視線の先に透明なフレームブロックを置く杖です。建築中の足場などに使えます。

[[TOC]]

| 操作 | 動作 |
|---|---|
| 右クリック | 視線の先にフレームブロックを設置 |
| Shift＋右クリック | その杖で置いたフレームブロックを一括撤去 |
| Shift＋ホイール | 設置距離を1〜15ブロックで調整 |
| Shift＋中クリック | 設置距離を既定値（5ブロック）へ戻す |

設置できる場所には白い枠を表示します。対象が空気でない場合は、枠を表示しません。蓄電容量は400,000 FEで、フレームブロック1個の設置に1,000 FEを使います（クリエイティブモードでは消費しません）。FE残量はツールチップで確認できます。電力が足りない場合は設置できません。

```embed:item id=advancedschematicannon:frame_block size=48 label=true
```

フレームブロックは仮設用の足場です。使い終わったら杖でまとめて撤去できます。
