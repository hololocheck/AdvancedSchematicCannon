# 範囲指定ボード

```embed:item id=advancedschematicannon:range_board size=48 label=true
```

フィラーモードで処理する直方体の範囲を指定します。手に持つと、画面下部に現在のモードを表示します。

[[TOC]]

通常モードでは、ブロックを右クリックしてPos1、次にPos2を指定します。空中を右クリックした場合は、視線の先64ブロックまでの位置を指定します。1点だけ指定した状態では、もう一方の点が視線の先へ追従します。Shift＋右クリックで範囲を解除します。

Alt＋ホイールで編集モードへ切り替えると、片方の点を調整できます。Shift＋ホイールで編集する点を選び、Shift＋右クリックで選択した点を解除します。Shift＋左クリックでは点の選択を外します（点の位置は残ります）。

Altを押している間は、モードの説明を表示します。F1でHUDを非表示にすると、この表示も隠れます。

指定後は、ボードを砲の概略図スロットへ入れてください。持っているだけでは、砲の処理範囲に反映されません。
