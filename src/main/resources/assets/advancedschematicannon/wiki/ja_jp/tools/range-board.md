# 範囲指定ボード

```embed:item id=advancedschematicannon:range_board size=48 label=true
```

フィラーモードで使う直方体の範囲を指定するアイテムです。
持っている間、画面下部に**モードバー**が出ます。

[[TOC]]

## 通常モード

| 操作 | 動作 |
|---|---|
| ブロックを**右クリック** | Pos1 → Pos2 の順に設定 |
| **Shift + 右クリック** | 範囲をすべて解除 |

Pos1 だけ決まっている状態では、**Pos2 が視線の先に追従**してシアンの枠が動きます。

## 編集モード

一度決めた範囲の片方だけを直したいときに使います。

| 操作 | 動作 |
|---|---|
| **Alt + ホイール** | 通常 ⇄ 編集 のモード切り替え |
| **Shift + ホイール** | 編集する点を なし → Pos1 → Pos2 と選択 |
| **Shift + 左クリック** | 選択中の点だけを解除 |

選択中の点は視線の先に追従します。

## モードバー

Alt を押している間、モードバーの下に**そのモードの説明**がスライドして出ます。
F1 で HUD を非表示にしているときは、このバーも出ません。

> [!NOTE]
> 範囲を決めたボードは、**砲の概略図スロットに入れて**使います。
> 入れないとフィラーモードは対象範囲を知りません。
