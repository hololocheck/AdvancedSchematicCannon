# 概略図モード

Createの概略図に従って施工するモードです。モードボタンをクリックすると、既存ブロックをどう扱うかを選べます。

[[TOC]]

![](bws:advancedschematicannon:wiki/screens/emc-schematic-cannon__options__ja_jp.png)

| 画面の設定名 | 動作 |
|---|---|
| 固体ブロック置換しない | 空気や、草など置き換えられるブロックの場所だけに設置 |
| 固体を固体で置換 | 空き場所と液体の場所に設置し、既存の固体ブロックは固体ブロックで置換（空気では消さない） |
| 固体を任意で置換（既定） | 空気を含む概略図の内容で置換 |
| 固体を空気で置換 | 概略図で空気になっている場所の固体を除去し、ブロックは空き場所にだけ設置 |

「不足ブロックスキップ」を有効にすると、どの供給元からも資材を取得できないブロックを飛ばして処理を続けます（飛ばしたブロックも設置済みに数えます）。無効（既定）の場合は、その箇所で資材が届くまで待機し、届くと自動で再開します。「ブロックエンティティ保護」を有効にすると、チェストなど、ブロックエンティティを持つブロックが既にある場所を上書きせずに残します。これらのスイッチは概略図モードの設定欄に表示されますが、設定は砲が保持し、フィラーモードの施工にも同じように適用されます。

画面の状態欄で、設置済み数、合計、進捗率、残数を確認できます。不足するブロックは名前を赤く表示します。
