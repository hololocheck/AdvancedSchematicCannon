# 概略図モード

Create の概略図をそのまま建てるモードです。

[[TOC]]

## 置換モード

既に何かが置かれている場所をどう扱うかを決めます。モード切替ボタンをクリックすると
4 つのアイコンと、その右に 2 つのスイッチ ([下の節](#switches)) が出ます。

![](bws:advancedschematicannon:wiki/screens/emc-schematic-cannon__options__ja_jp.png)

| 表示 | 動作 |
|---|---|
| **固体ブロック置換しない** | 空気の場所にだけ設置します |
| **固体を固体で置換** | 既存の固体ブロックを、概略図の固体ブロックで置き換えます |
| **固体を任意で置換** | 既存の固体ブロックを、空気を含む概略図の内容で置き換えます |
| **固体を空気で置換** | 概略図で空気の場所にある固体ブロックを壊します |

## 不足スキップと保護のスイッチ {#switches}

置換モードのアイコンの右に並ぶ、スキップのアイコンと盾のアイコンのスイッチです。どちらも最初は切ってあります。

| 表示 | 動作 |
|---|---|
| **不足ブロックスキップ** | 入れると、材料が手に入らないブロックを飛ばして次へ進みます (飛ばしたブロックも設置済みに数えます)。切っているときは、その場所で材料が届くのを待ちます |
| **ブロックエンティティ保護** | 入れると、チェストやかまどなどブロックエンティティを持つブロックがある場所は、そのまま残します。切っているときは、置換モードに従って上書きします |

スイッチは概略図モードの帯にだけ出ますが、設定は砲が覚えていて、フィラーモードで動かすときにも同じように効きます。

## 材料が足りないとき

不足ブロックスキップを切っている間は、足りないブロックがあっても砲はエラーで止まらず、その場所で**材料が届くのを待ちます**。
届けば続きから設置します (不足しているブロックの名前は、下の進捗の表示に赤で出ます)。
入れているときはそのブロックを飛ばします — AE2 に自動クラフトを頼んだブロックも、できあがるのを待たずに飛ばします。

## 進捗の見かた

ステータス枠には `設置済み/合計 (%)` と `残り: N ブロック` が出ます。
不足しているブロックがある場合はその名前が赤で表示されます。
