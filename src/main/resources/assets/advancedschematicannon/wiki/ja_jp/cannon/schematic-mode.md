# 概略図モード

Create の概略図をそのまま建てるモードです。

[[TOC]]

## 置換モード

既に何かが置かれている場所をどう扱うかを決めます。モード切替ボタンをクリックすると
4 つのアイコンが出ます。

![](bws:advancedschematicannon:wiki/screens/emc-schematic-cannon__options__ja_jp.png)

| 表示 | 動作 |
|---|---|
| **固体ブロック置換しない** | 空気の場所にだけ設置します |
| **固体を固体で置換** | 既存の固体ブロックを、概略図の固体ブロックで置き換えます |
| **固体を任意で置換** | 既存の固体ブロックを、空気を含む概略図の内容で置き換えます |
| **固体を空気で置換** | 概略図で空気の場所にある固体ブロックを壊します |

## 材料が足りないとき

足りないブロックがあっても砲はエラーで止まらず、その場所で**材料が届くのを待ちます**。届けば続きから設置します
(不足しているブロックの名前は、下の進捗の表示に赤で出ます)。

> [!NOTE]
> 以前の画面にあった「不足ブロックスキップ」「ブロックエンティティ保護」の切り替えは、今の画面にはありません。
> どちらも切った状態で動きます — 不足は待ち、チェストなど中身を持つブロックも置換モードに従って上書きします。

## 進捗の見かた

ステータス枠には `設置済み/合計 (%)` と `残り: N ブロック` が出ます。
不足しているブロックがある場合はその名前が赤で表示されます。
