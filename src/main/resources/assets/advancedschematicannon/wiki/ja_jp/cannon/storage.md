# 材料の供給とEMC

[[TOC]]

## 資材の供給元

ストレージの値にカーソルを合わせ、ホイールで切り替えます。MEネットワークと隣接コンテナの両方（「AE2/チェスト」）、MEのみ（「AEのみ」）、コンテナのみ（「チェストのみ」）を選べます。AE2を導入していない場合は「チェストのみ」になります。撤去モードでは、回収品の搬入先（「AEに搬入」「チェストに搬入」）を選びます。

![](bws:advancedschematicannon:wiki/screens/emc-schematic-cannon__storage__ja_jp.png)

## AE2との連携

AE2ケーブルを接続すると、給電とMEストレージへの接続を行えます。材料がない場合は自動クラフトを要求します。AE2側に対応パターンが必要です。

クラフト要求を出しても、資材が届くまでは取り出せません。砲はそのブロックで待機し、資材が届くまで取り出しを繰り返し試みます。届けば、自動で施工を再開します。「[不足ブロックスキップ](schematic-mode.md)」を有効にしている場合は、待たずに次のブロックへ進みます。

## EMCを使う

ProjectE導入時は、EMC概略図砲にEMC使用のスイッチと燃料スロットが表示されます。有効にすると、対応するブロックをEMCから錬成して設置できます。撤去したブロックのEMC変換にも対応します。

燃料スロットへ入れたアイテムは、砲が待機中でも所有者のEMCへ変換されます。変換には、所有者が設定され、ログインしていることと、アイテムにEMC価値があることが必要です。所有者がオフラインの間は変換せず、燃料を保持します。Ctrl＋左クリックで、インベントリから燃料スロットへ移動できます。

強化型概略図砲には、EMC用スロットとスイッチは表示されません。
