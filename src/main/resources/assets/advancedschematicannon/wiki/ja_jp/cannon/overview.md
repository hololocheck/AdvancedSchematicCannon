# 砲の画面

施工状況、資材、速度、モードを操作する画面です。砲を右クリックして開きます。

[[TOC]]

![](bws:advancedschematicannon:wiki/screens/emc-schematic-cannon__ja_jp.png)

上の画面は見本の砲で動いています: 一覧のマス目の名前、再生・速度・一時停止、再利用とプレビュー、所有者アイコン、停止の順に操作して見せます。

| 場所 | 内容 |
|---|---|
| 左側 | 必要ブロック一覧、または材料スロット |
| 右上 | 状態、進捗、現在のモード |
| 右側 | 電力、ストレージ、入出力、再生・停止 |
| 設定部分 | モード、速度、再利用、プレビュー、EMC |
| 右下 | 所有者と公開状態 |

## モードと速度

モードボタンの上でホイールを回すと、概略図・フィラーを切り替えます。クリックすると、現在のモードの細かな動作を選べます。

速度は値の上でホイールを回し、1〜256ブロック／tickに設定します。高い値ほど、一度に処理する量と消費電力が増えます。

## 切り替え設定

「再利用」は施工後も概略図を残す設定、「プレビュー」は対象範囲の枠表示です。「EMC使用」は、EMC概略図砲でのみ表示されます。

## 公開状態

右下の顔アイコンは所有者を示します。緑の公開状態では、だれでも画面を開いて設定を変更できます。赤の非公開状態では、所有者とサーバーの管理者（OP）だけが操作できます。

開始・一時停止・停止と、公開状態の切り替えは、どちらの状態でも所有者と管理者だけが行えます。施工は、所有者がサーバーにログインしている間だけ進みます。
