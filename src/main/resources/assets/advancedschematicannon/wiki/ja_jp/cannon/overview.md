# 砲の画面

[[TOC]]

## 画面の構成

| 位置 | 内容 |
|---|---|
| 左 | **設置ブロック一覧 / 材料スロット** (4 列 × 16 行) |
| 右上 | ステータス・進捗バー・現在のモード |
| その下 | 電力ゲージ / ストレージ選択 |
| その下 | 入出力スロットと 再生・一時停止・停止 |
| その下 | モード切替 / 速度 |
| その下 | 再利用・プレビュー・EMC のトグル |
| 右下 | 所有者アイコン |

## 左側のマス目

**概略図モード**では、概略図に必要なブロックとその個数が一覧で出ます。
**フィラーモード**では、同じマス目がそのまま**材料を入れるスロット**になります。

マス目の上でホイールを回すとスクロールします。

## モードの切り替え

モード切替ボタンは 2 通りの操作を持ちます。

- **ホバーしてホイール** — 概略図モード ⇄ フィラーモードを切り替えます
- **クリック** — ボタンの真下に、今のモードの細目アイコンが並びます

細目は概略図モードなら[置換モード](schematic-mode.md) 4 種、
フィラーモードなら[フィラーモジュール](filler-mode.md) 7 種です。

## 速度

**速度**は 1 tick あたりに設置するブロック数で、**1〜256** の範囲です。
値の上でホイールを回して変更します。大きくすると速い代わりに電力消費が増えます。

## トグル

| 名前 | 内容 |
|---|---|
| **再利用** | 完了後も概略図を消費せず残します |
| **プレビュー** | 設置範囲の枠をワールドに表示します |
| **EMC使用** | EMC概略図砲でのみ表示。EMC を使って設置します |

## 所有者アイコン

右下のプレイヤーの顔は、この砲を設置した人です。**枠の色が権限を表します。**

- **緑 = 公開** — 誰でも設定を変更できます
- **赤 = 非公開** — 所有者と op だけが変更できます

クリックで切り替えられますが、**切り替えられるのは所有者だけ**です。
