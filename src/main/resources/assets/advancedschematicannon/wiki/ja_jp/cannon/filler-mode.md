# フィラーモード

概略図を使わず、[範囲指定ボード](../tools/range-board.md)で決めた空間に施工・消去・撤去を行うモードです。

[[TOC]]

1. ボードで範囲を指定し、砲の概略図スロットに入れます。
2. 建築する場合は、左側の材料スロットにブロックを入れます。
3. 動作を選び、再生ボタンで開始します。

![](bws:advancedschematicannon:wiki/screens/emc-schematic-cannon__filler__ja_jp.png)

上の画面は見本の砲です: 範囲指定ボードと材料を shift クリックで入れ、壁作成モードで再生して止め、撤去モードで再生するとマス目が範囲内のブロックの一覧に変わるところ (実機では撤去モードで範囲の決まったボードを入れた時点でも一覧が出ます)、最後にボタン上のホイールで概略図モードへ戻るところを見せます。

| 画面の設定名 | 内容 |
|---|---|
| 埋め立てモード | 範囲内を下の段から材料で埋める。範囲内のモブは取り除く |
| 完全消去モード | 範囲内を上の段から空気にする（ブロックは回収しない） |
| 撤去モード | 範囲内のブロックを上の段から回収する |
| 壁作成モード | 範囲の側面をつくる |
| タワーモード | 底面から柱状に積む |
| 箱作成モード | 外周の6面をつくる |
| 円壁作成モード | 範囲に内接する円筒の壁をつくる |

> [!NOTE]
> 既にあるブロックの扱いは、[概略図モード](schematic-mode.md)で選んだ置換モードと2つのスイッチに従います。「固体ブロック置換しない」「固体を固体で置換」では、完全消去・撤去でブロックは消えません。

撤去では、左側を範囲内のブロック一覧として表示します。ボードを入れると範囲内を走査して一覧をつくります。走査できる範囲は50,000ブロックまでで、超えるとエラーになります。回収先は「AEに搬入」（MEネットワーク）または「チェストに搬入」（隣接コンテナ）から選べます。回収先がいっぱいになると、施工は一時停止します。EMC概略図砲でEMC使用を有効にしている場合は、回収品をEMCへ変換できます。
