# フィラーモード

概略図を使わず、**[範囲指定ボード](../tools/range-board.md)で指定した範囲**に対して
一括で操作するモードです。

[[TOC]]

## 使い方

1. [範囲指定ボード](../tools/range-board.md)で範囲を決めます。
2. そのボードを砲の**入出力の概略図スロット**に入れます。
3. 左のマス目 (4 列 × 16 行) に**使う材料**を入れます。
4. モジュールを選んで再生します。

## モジュール

モード切替ボタンをクリックすると 7 つのアイコンが出ます。

| モジュール | 動作 |
|---|---|
| **埋め立てモード** | 範囲内の空気を材料で埋めます |
| **完全消去モード** | 範囲内をすべて空気にします |
| **撤去モード** | 範囲内のブロックを回収します |
| **壁作成モード** | 範囲の側面だけを作ります |
| **タワーモード** | 範囲の底面から柱状に積みます |
| **箱作成モード** | 範囲の外殻 (6 面) を作ります |
| **円壁作成モード** | 範囲に内接する円筒の壁を作ります |

## 撤去モードだけの挙動

**撤去モード**では左のマス目が材料スロットではなく、
**範囲内にあるブロックの一覧**に変わります。回収先はストレージ設定に従います。

- **AEに搬入** — ME ネットワークへ入れます
- **チェストに搬入** — 隣接コンテナへ入れます

EMC概略図砲で **EMC使用** を入れている場合、回収したブロックを EMC に変換できます。
