# Getting started

```embed:item id=advancedschematicannon:enhanced_schematic_cannon size=48 label=true
```

[[TOC]]

## 1. Place the cannon and give it power

The cannon runs on **FE**, with an internal buffer of **100,000 FE**. Attach any FE cable
or generator next to it. If you connect an AE2 cable, that single connection provides
**both power and access to the ME network**.

## 2. Insert a schematic

Right-click the cannon to open its screen and put a Create schematic into the left slot of
the **I/O** row.

## 3. Line up materials

Choose where materials come from with the **Storage** control on the right.

- **Extract from AE2 & Chests** — search both
- **AE only** — the ME network only
- **Chests only** — adjacent containers only

## 4. Start

Press the **play button** to begin. Pause and stop sit on the same row.

Progress, remaining block count and any missing block are shown in the **status panel** at
the top of the screen.

> [!NOTE]
> If materials run out the status becomes **Error** and the missing block is named. When
> connected to AE2 the cannon will [request autocrafting](cannon/storage.md).
